# 设计风格指引（Design Language）

> 定位: dsh-plugins 插件的视觉语言总纲。**所有取值以宿主(deepseek-harness)实测为准**,本文件只定「规则 + 语义」,不复制 token 值(查 tokens.md / design-platform.css)。
> 参考组织方式借鉴主流设计体系(Material/Ant Design/HIG 的分层与状态矩阵),风格语言为本项目基于宿主实测自研。

## 一、设计原则

1. **宿主统一(最高原则)**: 插件运行在 DeepSeek Harness 内,视觉语言跟随宿主;宿主有同款实现的,照抄其取值,不自创。
2. **克制**: 装饰最小化。无渐变滥用、无多余阴影、无动画炫技;信息密度与留白跟随宿主节奏。
3. **语义优先**: 颜色/间距/圆角都表达语义(状态、层级、可交互性),不表达装饰。
4. **可判定**: 每条规则可脚本/人工检查(白名单、禁项、配方);偏离必记 ADR。
5. **暗色一等公民**: 样式默认同时适配明暗主题,不写主题分支,靠 alias token。

## 二、排版 Typography

- 字阶(宿主官方体系,正文基准 13px):
  - 11 caption(徽章/时间/操作者) · 12 辅助 · 13 正文 · 14 次标题 · 15–16 标题 · 19–22 大标题 · 26 页面大标题
- 行高: 正文 13/22(1.7);小字 11–12 行高 18;标题 14–16 行高 22–24。
- 字重: 常规 400,强调 500–600(宿主 Figma 510 权重渲染为 500);标题 ≤600,禁 700+。
- 字体族: 跟随宿主(系统 UI 栈),**不引入自定义字体**。
- 数字: 时间/数量用 `tabular-nums`(变更记录时间等)。
- 文字层级映射: 主文 label-primary / 次文 secondary / 辅助 tertiary / 占位 dimmed / 说明 caption(见 tokens.md §2.1)。

## 三、色彩语义 Color

- 插件样式**只允许**引用 `--dsw-*` alias 语义层(见 tokens.md §二);禁硬编码色值(唯一例外: 主按钮文字 #fff)。
- 语义映射(权威表见 tokens.md):
  - 文字: label-* 五档
  - 边框: border-l1(最轻)/l2(常规)/l3(hover 强)/l4(选中最强)
  - 背景: bg-base(页面/浮层)/bg-layer-2(代码块/气泡/清单项)/interactive-bg-hover(悬停底)
  - 状态: state-business-*(主操作/选中/caret)/state-error-*(错误)/state-success-*(成功)/state-warn-*(警告)
- 暗色红线: 禁静态浅色底做 hover/常态背景;focus ring 仅按钮,用 `rgba(65,118,230,.18)`。

## 四、间距节奏 Spacing

- **宿主组件实测归纳**(非自创体系): 档位 = 宿主 CSS 实测值全集(4/6/8/10/12/14/16/20/24/28/32/36 等),按场景映射。
- 常用节奏: 4(图标内隙/gap)/8(标签与控件)/12(浮层头部纵向)/14(按钮 padding/顶栏纵向)/16(表单元素间/看板四边/卡片内边距横向)/20(抽屉内边距纵向)/24(抽屉内边距横向)/28(icon 按钮尺寸)/32(大区块)。
- **禁自由发挥间距**: 非档位值必须记 ADR。
- 交互元素最小触达: 28×28(icon 按钮),按钮 36/28 两档。

## 五、圆角语言 Radius

- 白名单(宿主实测): `6` 小控件(胶囊除外) · `8` 输入/代码块/气泡/卡片旧款 · `12` 卡片 · `14` 浮层 · `18` 按钮 md(胶囊) · `14` 按钮 sm · `22` Composer/主输入框 · `999px` 胶囊 · `50%` icon 按钮。
- **白名单之外禁用**;不同控件圆角=层级语言(浮层>卡片>输入>控件)。

## 六、层级阴影 Elevation

- `--dsw-shadow-lv1` 卡片 · `lv2` 输入浮起/小浮层 · `lv3` 浮层/抽屉。
- 对话流工具卡**不加阴影**(与宿主流内工具卡一致);层级优先靠边框(border-l1/l2)+背景分层,阴影只用于「浮起」。

## 七、动效 Motion

- 过渡: 150ms `cubic-bezier(.4,0,.2,1)`(宿主同款)。
- 浮层出现: 240ms 渐入。
- 状态指示动画: 仅 loading(纯 CSS,不引库)。
- **禁自创动画**: 无弹跳/位移花活;hover/active 一律背景/颜色过渡。

## 八、图标风格 Iconography

- 来源: 宿主 `ic_ds_*` 图标集(vendor submodule, MIT),经 `packages/ui/host/icons.ts` **直接 re-export**(同一份源码,无漂移),命名沿用宿主。
- 尺寸档位: 12 / 14 / 16 / 20(宿主四档);glyph 默认 16。
- 风格: outline 线性,stroke 1.3,圆头线帽(round cap/join);fill 图标仅宿主同款场景(close/loading)。
- 使用规则: 图标按钮 glyph 一律 16,容器 28×28 圆形(§组件规范);**禁自绘/第三方图标集**;确无图标 → 记 ADR 从宿主集补充。
- 颜色: `currentColor` 继承文字色,不单独上色。

## 九、文案语气 Copy

- 界面文案一律中文,简洁陈述,无感叹号/emoji。
- 按钮动词优先(保存/取消/删除/确认);错误提示说明原因+补救(禁止裸 "Error")。
- 状态与空态: 一句引导 + tertiary 色;loading 文案用「…中」而非「加载中…」风格需与宿主一致(实测对齐)。
- 开发注释/代码注释: 英文。

## 十、交互细节 Micro-interaction(键盘与操作契约)

> 与宿主交互习惯一致,逐组件细则见 components.md「交互」节;此处为全局通则。

1. **Enter 发送**: 输入框聚焦时 Enter 提交/发送;Shift+Enter 换行(多行输入)。
2. **Esc 关闭**: 浮层/弹窗/查看器 Esc 关闭(蒙层点击不关闭,ADR-4)。
3. **Tab 顺序**: 控件按视觉顺序可 Tab 遍历;focus-visible 必须可见(按钮 2px accent ring)。
4. **快捷键**: 浮层内 Ctrl/Cmd+Enter 确认;列表删除需确认(二次确认或撤销)。
5. **disabled**: 按钮 opacity .4 + `cursor:not-allowed`;不改变布局。
6. **hover 反馈**: 可交互元素必须有 hover 反馈(背景变化);纯展示元素禁止 hover 效果。
7. **focus 零高亮**: 输入类控件零高亮(无 ring/边框不变),caret 品牌蓝(ADR-2);按钮类保留 ring。
8. **滚动**: 长内容容器内部滚动,滚动条样式跟随宿主 scrollbar tokens。
9. **防误触**: 破坏性操作(删除/清空)需确认;确认按钮 danger 变体。
